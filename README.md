# 🤖 AI Interview Trainer Agent

## 📌 Overview
This project is an AI-powered Interview Trainer built using IBM Watsonx Orchestrate and Granite model. It simulates real interview scenarios, evaluates user responses, and provides structured feedback.

---

## 🚀 Features
- Mock interview simulation
- Real-time answer evaluation
- Strengths and weaknesses analysis
- Resume-based questions
- Final performance report
- Beginner-friendly interaction

---

## 🧠 How It Works
1. User starts the interview
2. Agent asks questions based on role/difficulty
3. User answers
4. Agent evaluates and gives feedback
5. Final report is generated at the end

---

## 🛠️ Tech Stack
- IBM Watsonx Orchestrate
- Granite Foundation Model
- AI Prompt Engineering

---

## 🎯 Use Cases
- Interview preparation
- Skill assessment
- Practice for technical & HR questions

---

## 📊 Sample Questions
- Tell me about yourself
- Difference between array and linked list
- Describe a team conflict you handled

---

## 🚀 Deployment
The project is deployed using IBM Watsonx Orchestrate and runs in a live environment within the platform.
